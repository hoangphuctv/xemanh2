# XemAnh2

XemAnh2 là trình xem ảnh desktop nhẹ, nhanh và đa nền tảng.

Mục tiêu là cung cấp trải nghiệm xem ảnh đơn giản, phản hồi nhanh và giao diện native, không phụ thuộc game engine.

Hỗ trợ:
- Windows, macOS, Linux
- JPEG, PNG, BMP, GIF, WebP, TGA
- Điều hướng ảnh trong cùng thư mục
- Zoom bằng phím hoặc chuột
- Fullscreen

Công nghệ chính:
- Rust
- winit
- softbuffer
- image
- kamadak-exif
